# GameSir Native Linux — PRE-ALPHA source candidate

This is a separately sanitized source snapshot, not the private development
Git history and not a published/installed release. No .git data, commit email,
private logs, raw captures, manufacturer binaries or host package inventory
are included. The original development repository is preserved privately.

Private home/workspace paths and host labels were generalized, personal
tester names in historical reports anonymized, and private session AGENTS.md
replaced with public contributor rules. Synthetic test paths were generalized.
Protocol/runtime code, required author attribution and licenses were preserved.
Historical evidence hashes describe private originals, not transformed reports.
PUBLIC_SOURCE_MANIFEST.json records the exact base commit, transformation
categories and file hashes without the private replacement values.

Use the full source tree for make test. The component source archives are
smaller build subsets. Source-only candidate: no Arch binary package and no
prebuilt kernel module is offered. Review README.md, docs/INSTALLATION.md,
docs/RELEASE_AUDIT.md and docs/PUBLIC_RELEASE_CHECK.md before any installation.
Gyro calibration is paused. Trigger-game integration, ZZZ coverage, PM and
repeated-reconnect validation retain the documented limits. No stability claim.

Publication, remote/history/identity selection, tags and pushes still require
explicit maintainer approval. The private development history is NOT approved.
